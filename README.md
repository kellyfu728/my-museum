# 🏛️ My Museum

> **Things I don't want to forget.**

[**中文 README**](README_zh.md)

My Museum is a small personal archive for collecting the things that make me stop and think:

a beautiful sentence, an interesting piece of dialogue, a plot idea, a character dynamic, a writing technique, a scene, or simply an idea that I don't want to lose.


---

## ✦ What is My Museum?

My Museum is a personal collection of creative fragments and inspirations.

It is not a reading tracker, a Goodreads clone, or a productivity app.

Instead, it is a place to keep the small things that stay with me.

Each entry is treated as an **exhibit** in a personal museum.

For every exhibit, I can record not only **what I found**, but also:

> **Why did I save this?**

That question is at the heart of the project.

---

## ✦ Why I Made This

When I read Chinese or English fiction, I often find myself stopping for small things:

- a sentence that is beautifully written
- a piece of dialogue that feels particularly natural
- a plot development that I really like
- an interesting relationship between characters
- a clever storytelling idea
- a scene with a specific atmosphere
- a writing technique I want to learn from

I used to save these things in scattered notes, screenshots, or documents.

I wanted somewhere that felt less like a database and more like a **personal collection**.

So I built My Museum.

## ✦ How an Exhibit Works

Each exhibit contains:

**What did you find?**

The actual quote, idea, observation, or creative fragment.

**Why did you save it?**

A personal note about what made it interesting to you.

Optional information includes:

- Type
- Source
- Tags
- Date added

The goal is not to create perfect notes.

It is simply to remember **why something caught your attention**.
